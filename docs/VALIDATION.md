## 验证边界

**没有使用 Mili 原曲做听感或逐拍同步校准。** 上述 WAV 是诊断音，不是替代配乐，也没有打包交付。

浏览器环境的管理策略阻止直接访问本机 HTTP 地址，因此浏览器 UI 测试针对单文件离线 HTML，在内存页面中执行；HTTP 后端通过独立请求测试。没有把二者描述成已经完成的浏览器到实时服务器全链路端到端测试。

当前环境没有 mpv，终端真实音频后端未做实际设备联调；已测试的真实终端流程使用无声时钟。Windows、macOS、Safari 和 Firefox 尚未实机验证。仓库包含 GitHub Actions 工作流；远程 CI 状态请查看仓库的 Actions 页面，不应把本地测试结果视为所有平台的验证结果。

美术全部为程序化图形或明确标记的占位稿；人物像素辨识度、最终绘图转换效果和成片观感需要用用户原画继续验证。

## 可复现命令

```sh
python3 -m unittest discover -s tests -v
python3 tools/export_preview.py
# 可选：安装测试工具，选择已安装的 Chromium 或用 Playwright 安装浏览器
python3 -m pip install playwright
python3 tools/browser_smoke.py --browser /path/to/chromium
```

浏览器脚本输出到 `test-results/`，该目录已被 Git 忽略；诊断音在临时目录创建并自动删除。导出 HTML 是固定分辨率 6 FPS 的抽样预览，含准确的分镜边界帧；实时渲染器目标 24 FPS，不保证每台设备恒定达到。
