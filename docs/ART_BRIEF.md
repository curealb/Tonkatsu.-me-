# Tonkatsu.(me)｜绘图需求 v0.1

## 作品的主体

不是炸猪排广告，而是「月村手毬如何看待炸猪排」。食物要诱人，角色反应要成立：表面冷静 → 被香味吸引 → 克制失效 → 吃到以后满足。所有独白和剧情是这支 MV 的二创设定，不当作游戏原作设定或官方台词。

原型现有的角色图只是通用字符头像占位，不是对角色正式形象的完成稿。请按你熟悉的手毬造型绘制，保留发型轮廓、刘海和眼神等识别特征。第一轮不需要背景、封面、标题字或场景全景。

## 画风规范：原画是二次元赛璐璐，成片是终端字符动画

这是本项目**推荐的统一美术方向**，不是声称官方规定，也不是要求你先手工画 ASCII：

1. **角色原画**：沿用月村手毬的辨识性造型（青灰色长发、绿色眼睛、层次刘海）；轻微三分之二侧面，清爽日系动画线稿、2–3 档清晰明暗块面（赛璐璐上色），不要厚涂写实、照片风或过于复杂的花纹。官方角色资料可参考 https://gakuen.idolmaster-official.jp/idol/temari/ 。
2. **情绪表演**：从目光克制、眼神偷瞄、终于咬下，到闭眼满足。四张应保持同一机位、相同眼睛高度/头顶/肩线；尤其优先画清楚眼睛、嘴巴轮廓、筷子与炸猪排的分离关系。
3. **食物原画**：日系动画食物特写，外壳金黄、边缘大块面酥脆质感、切面熟肉偏暖白；强调厚度、粗细层次和不规则边缘，避免使用细碎写实噪点或满图散射光。
4. **最终画面**：由程序转成 ASCII 并叠加黑底终端 UI、CRT 扫描线和故障特效。**不要**在人物 PNG 上预画字符、发光、故障、爱心、字幕或终端窗口；由动画引擎统一控制这些效果。
5. **明度检查**：在作画软件里把图暂时转成灰度，并缩小到近似 40 列宽观察；若手毬的眼睛、刘海、手部动作不能一眼辨认，就简化纹理、加粗关键线、扩大眼睛/嘴部明暗差。

### 建议色彩关系

服装与头发以深灰蓝、青绿色为主，食物用饱和但不过曝的金黄，肌肤和蒸汽用暖白，故障仅用少量红色。现有渲染器 `tonkatsu/canvas.py` 的实际终端色板为蓝 `#76BFFF`、金 `#FFC879`、白 `#EEF5FF`、粉 `#FFA8C6`、故障红 `#FF7E8A` 等；这些是**程序 UI 色值**，不要求原画严格照此取色，图像转换目前以灰度和透明通道为主。

整体情绪是**「冷淡外表 × 对炸猪排难以克制的幸福感」**，不是食物广告、油腻写实，也不是满屏夸张 Q 版表情。

## 第一批：四张角色图（必须，P0）

统一画幅 **1024×1024，RGBA 透明 PNG**。同一角度、同一头身比例、同一裁切；人物居中偏左一点，视线朝画面右侧的炸猪排。大约到胸口或腰上的半身即可。四张图不要改变头顶、眼睛和肩线的基准位置，这样切换表情时不会跳动。

人物将放在画面左侧，食物在右侧。请预留右侧筷子和伸手的空间。角色轮廓宽度占画幅约 60–75%，头部尽量大；空白边距各留约 8%。颜色可以正常绘制，但要在转为灰度时仍能读出眼睛、嘴巴和发型边缘。

### 01 / `temari_calm.png` —「我没有在等。」

三分之二或轻微三分之二侧面的半身。身体姿态克制，嘴巴闭合或非常轻微抿嘴；视线看向右侧，但不夸张地转头。表情的重点是「表面冷静，不肯先表现期待」，不是厌恶食物，也不是愤怒。双手可以抱臂或收在身前；右侧必须留出后续食物动画空间。

使用段落：开场启动、配菜选择、公开发言与脑内状态不一致的段落。

### 02 / `temari_tempted.png` —「香味自己飘过来的。」

保持同一身体和头的位置。眼睛更集中地追踪右侧食物，瞳孔／高光可以稍大，眉眼比第一张松动；嘴角或嘴形显示「快绷不住了」，不要把她画成完全不同性格。可有小幅前倾，但不改变整体基准太多。不要把汗滴、星星、爱心、蒸汽烘焙进图里，程序会另加。

使用段落：香气、圆盘、无限食欲、盘子离开、自控异常。

### 03 / `temari_bite.png` —「我开动了。」

同一构图。右手持筷子从画面右下方向嘴边移动，夹一小块炸猪排；嘴刚接触或正在咬下。可以闭眼或微眯眼，表达「终于吃到了」。猪排块必须有清楚外轮廓，避免筷子、脸和头发融成黑团。不画文字音效；`CRUNCH`、面包糠飞散和整块食物递减由程序生成。

使用段落：第一次开动，后段连续「执行」的咬食高潮。

### 04 / `temari_happy.png` —「好吧。我就是喜欢。」

同一构图。放松的闭眼或眯眼，嘴巴闭合咀嚼，脸颊可以轻微鼓起；不要做夸张张嘴大笑。满足感比第二张明确，但仍与手毬的表现气质连贯。可有很轻的脸红，不能依赖脸红作为唯一表情信息，因为 ASCII 转换会丢失颜色。

使用段落：幸福参数、心跳、爱与循环、结尾再来一块。

## 第二批：两张食物图（可后补，P1）

食物目前有程序化字符图形，缺少这些图片不影响播放。

### 05 / `tonkatsu_hero.png` — 完整炸猪排主视觉

**1536×1024 透明 PNG**，轻微俯视约 30 度。中心是一块厚实、金黄、酥脆的炸猪排，外形略有不规则，不要画成一枚完全光滑的椭圆饼。面包糠以清楚的大颗粒纹理表达，不要全靠细小噪点。可以切成几条但仍保持完整轮廓。盘子若绘制，请用简单白盘，不要复杂花纹。不要把大量蒸汽、爱心、发光、桌面和配菜并入图中。

画幅中食物占宽约 80%、高约 55%；提供的图会成为 `Stage.food()` 的整体食物层，切口／消失动画是近似遮罩，不是精确骨骼动画。

### 06 / `tonkatsu_slice.png` — 一块切面

**1536×1024 透明 PNG**，单独一条或一块厚切猪排，切面朝向观看者。清楚区分金色外壳、浅色熟肉和少量肉汁高光。不要画生肉。轮廓简洁，切面占主体面积，放大后能让观众感到「外酥内软」。可提供一个无筷子的版本，便于程序组合。

## 技术要求

- 最终格式 PNG，透明背景。不要棋盘格背景、白底截图、标题、歌词、水印或软件界面。
- 角色四图必须共用画布尺寸和位置基准；不要分别裁切透明边。
- 优先清晰外轮廓和大明暗面；细密网点、纤细发丝、长睫毛会在字符化后消失。
- 可额外保留 PSD / Clip 工程供你自己修改，不需要提交给播放器。
- 不需要画故障、进度条、终端边框、油锅粒子、字幕或爱心；这些由程序生成。

## 交付位置与替换

```text
assets/source/temari_calm.png
assets/source/temari_tempted.png
assets/source/temari_bite.png
assets/source/temari_happy.png
assets/source/tonkatsu_hero.png
assets/source/tonkatsu_slice.png
```

收到任意一张都可以先测试，不必等齐全。角色先转 40 列，运行时按窗口缩小：

```sh
python3 -m pip install -r requirements-art.txt
python3 tools/import_art.py assets/source/temari_calm.png --slot temari_calm
python3 preview.py
```

若深色发型在转换后看不见，可试 `--mode edges`；纯轮廓形态可试 `--mode silhouette`。`--output /path/to/test.txt` 仅生成试稿，不替换正式素材槽。软件当前没有边缘语义重绘功能；最终字符辨识度需要根据实际原图做一轮调整。

**优先交付顺序：冷静 → 嘴馋 → 咬下 → 幸福；食物两张之后再补。**
